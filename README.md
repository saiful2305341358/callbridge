# CallBridge ♠

A feature-rich, high-polish Call Bridge (CallBreak) trick-taking card game built for Android and Web using modern Material 3 design.

## Features

- **4-Player Tactical Gameplay**: Play South (You) against 3 smart AI bots (Rahul, Dev, Priya) with adaptive bidding and tactical card play.
- **Permanent Trump (Spades ♠)**: Authentic Call Bridge rules with Spades as permanent trumps, strict follow-suit enforcement, and trumping mechanics.
- **Interactive Bidding Phase**: Intuitive call chips (1–8 tricks) with built-in AI bid recommendations based on hand analysis.
- **Live Trick Table**: Responsive casino felt surface, dynamic player turns, compass-aligned trick arena, winner highlights, and card sorting (by Suit or by Rank).
- **Match Scorecard**: Full 5-round (or 3/7/10 round) scorecard table tracking Bids, Tricks Won, Round Points (+0.1 per extra trick / -Bid penalty), and live rankings.
- **Physical Card Table Scorekeeper**: Standalone digital calculator and scorecard companion for scoring in-person games played with physical playing cards.
- **Customizable Felt & Cards**:
  - Table felt colors: Casino Emerald, Midnight Navy, Royal Burgundy, Carbon Onyx.
  - Card back styles: Classic Navy, Royal Ruby, Forest Emerald, Imperial Gold.
- **Rulebook & Guide**: Comprehensive in-app guide covering card ranks, dealing, calls, trick play rules, and strategy tips.
- **Career Records**: High scores, win rates, and match history logs.
